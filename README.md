# JAMIA Sepsis Transportability

Reproducible source code and analysis workflow for the sepsis model transportability study.

## Main analysis

The complete analysis workflow is provided in:

`Sepsis_Transportability_Q1_FINAL.ipynb`

The notebook includes model development, external transportability assessment, calibration analysis, recalibration, recoverability analyses, and robustness evaluations.

## Data

This study uses the PhysioNet/Computing in Cardiology Challenge 2019 sepsis dataset. Raw patient-level data are not redistributed in this repository.

## Software environment

Analyses were performed using Python 3.14.7.

Key package versions are listed in `requirements.txt`.
